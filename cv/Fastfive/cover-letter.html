클라우드 세일즈에 지원하면서 파는 것을 제가 먼저 알아야겠다고 생각했습니다. AWS Cloud Practitioner와 AI Practitioner 자격증을 따고, 팀 프로젝트에서는 직접 AWS S3에 데이터를 저장하는 백엔드를 만들고 Supabase 같은 클라우드 위에 AI 서비스를 올려 봤습니다. Unity로 만든 로봇 팔 데모는 클라우드에 올려 두고 다시 꺼내 쓰는 것까지 해 봤습니다. 직접 만들어 보니, 고객 앞에서 기능을 늘어놓기보다 '그래서 이게 무엇을 해결해 주는가'를 먼저 말해야 한다는 걸 알게 됐습니다.
